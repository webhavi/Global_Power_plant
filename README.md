📊 About the Dataset
The Global Power Plant Database is a comprehensive dataset containing information on thousands of power plants worldwide. It includes details such as:
🌍 Country and location
⚡ Installed generation capacity (MW)
🔋 Primary fuel type (Coal, Gas, Hydro, Solar, Wind, Nuclear, etc.)
🏭 Plant name and ownership
📍 Geographic coordinates
This dataset enables powerful analysis of global energy infrastructure and supports predictive analytics for power generation capacity.
